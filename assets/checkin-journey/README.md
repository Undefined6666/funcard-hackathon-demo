# Daylight check-in journey

These three backgrounds were generated for the “人格登机计划” daylight chapters and then resized to 1536 × 960 WebP assets.

- `01-avatar-studio.webp`: a sunny pixel-art departure studio with wardrobe, portrait mirror and mint boarding gate.
- `02-door-hall.webp`: a warm terminal hall with exactly four distinct doors: open, ajar, keyed and password-protected.
- `03-packing-room.webp`: a daylight baggage workshop with twelve empty display alcoves for the personality objects.

Prompt direction: polished 2D pixel-art game background, cream/mint/coral/gold palette, warm daylight, papercraft travel-journal details, crisp hard-edged pixels, no characters, no legible text, and a composition deliberately distinct from the later cinematic night-route scenes.
