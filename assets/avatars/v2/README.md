# Modern pixel avatar set

These ten character sets were generated for the FunCard Hackathon MVP with the built-in OpenAI image generation tool, then normalized into production-ready PNG sprite sheets with `scripts/slice-avatar-sheet.mjs`.

Each character contains:

- `<id>-front.png`: 170 × 204 front-facing card portrait.
- `<id>-walk.png`: 1020 × 204 horizontal sheet with six left-facing walk frames.

Shared generation direction: refined Japanese-inspired pixel art, clean hard pixel edges, modern daily clothing, one front pose followed by six consistent side-walk poses, no weapons, armor, medieval clothing, fantasy props, text, borders, or shadows.

Outfit directions:

- `female-coral`: coral bob, denim jacket, graphic tee, beige wide-leg trousers.
- `female-lilac`: black high ponytail, lilac cropped hoodie, cycling shorts, high-tops.
- `female-teal`: black blunt bob, teal blazer, navy pleated skirt, loafers.
- `female-sun`: twin buns, yellow varsity jacket, teal skort, platform sneakers.
- `female-denim`: blue-black side ponytail, cream shirt, indigo workwear overalls.
- `male-mint`: tousled brown hair, mint bomber, white tee, navy joggers.
- `male-coral`: silver crop, coral overshirt, black tee, khaki cargo trousers.
- `male-navy`: black curls, oversized navy hoodie, gray shorts, high-tops.
- `male-mustard`: chestnut side part, mustard cardigan, striped tee, straight jeans.
- `male-tech`: platinum crop, teal utility vest, black base layer, charcoal wide trousers.
